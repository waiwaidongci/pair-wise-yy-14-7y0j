# hxyfront-62013 木结构灾后续作抢护台

强风过境后，古建保护站用于排定受灾建筑抢护次序的前端工作台。

## 功能

- **构件登记**：建筑、构件编号、木材种类、榫卯类型（燕尾榫/透榫/半榫/箍头榫/管脚榫/斗口榫）、
  截面尺寸、病害位置、初测变形，并连接梁架→斗拱→柱网的传力下游关系。
- **复测与建议失效**：保存任一项复测值（木材、榫卯、截面、变形、病害位置）后，
  封存的修缮建议按值签名判定为失效，病害标记和传力关系边颜色立即重算；
  重新核对封存新版本后，构件才回到抢护队列。旧版建议全部留档可查。
- **抢护队列**：每栋建筑临时支撑位容量有限，容量不足时先排队；
  占位优先值 = 复测变形 + 下游构件数 × 6 + 严重病害加权 25，处理中占住支撑位，
  完成修缮释放后候队者按序补位。
- **并发处理**：可在两个浏览器标签页以不同测绘员身份同时操作。
  两人抢同一构件或同一支撑位时先处理者生效，后到者操作被拒、现场值保留进冲突记录。
- **续作**：队列、旧版留档、冲突、未完成（处理中）的状态都存于 localStorage，
  并通过 BroadcastChannel / storage 事件跨标签页同步；关掉页面再打开仍在。

## 技术栈

React 19 + Vite + TypeScript，无后端。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:62013
npm run build
```
